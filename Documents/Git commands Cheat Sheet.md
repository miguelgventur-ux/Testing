### **Git commands Cheat Sheet**



**Caveat commands | Troubleshooting**

git pull origin main --allow-unrelated-histories		- PULL REQUEST TO MATCH ROOT COMMIT (README.md)

git branch -m master main 					- RENAME A BRANCH



**Git local commands (Information and movement)**

git init							- START UP Git

git log								- BRANCH COMMITS

git branch							- BRANCHES

git status							- LOG OF CHANGES BEFORE COMMIT

git checkout 							- MOVE TO A DIFFERENT BRANCH



**Git local CRUD commands**

git clone (GitHub repo url)					- CLONE REPO TO LOCAL DIRECTORY

git add (file name)						- ADD FILE

git commit -m 'commit message'					- CONFIRM BRANCH CHANGES

git reset (file name)						- RESET FILE TO BRANCH DEFAULT



**Git Branch commands**

git checkout -p new-branch					- CREATE NEW BRANCH

git checkout -d new-branch					- DELETE BRANCH



**Connections with GitHub**

git remote add origin (url)					- CONNECT TO GitHub

git remote remove origin					- DISCONNECT TO GitHub

git push -u origin main	 |  git push				- PUSH DEFAULT TIMELINE

git push -d origin(remote name) main				- DELETE BRANCH GitHub

git pull							- PULL TIMELINES' NEW DATA



**Other commands**

git config --global user.email					- ADD EMAIL

git config --global user.name					- ADD USERNAME
